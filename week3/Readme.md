โจทย์ที่ 1: เพิ่มหมวดหมู่ธุรกรรม\
 เพิ่ม `<select>` ให้ผู้ใช้เลือกหมวดหมู่ได้ เช่น อาหาร, เดินทาง, ช้อปปิ้ง, เงินเดือน, หรืออื่นๆ และนำชื่อหมวดหมู่หรือไอคอนหมวดหมู่ไปแสดงผลร่วมกับชื่อรายการในแท็ก `<li>` ไฟล์ Html

โจทย์ที่ 2: เพิ่มตัวกรองและค้นหารายการ (Filter & Search Bar)\
เพิ่มช่องค้นหา (Search Input) สำหรับค้นหาตามชื่อรายการแบบ Real-time (พิมพ์แล้ว Filter ข้อมูลทันที)

โจทย์ที่ 3: แสดงประวัติรายการทั้งหมด\
แสดงรายการเรียงตามลำดับ พร้อมแสดง ID/ลำดับ, ประเภท, ชื่อรายการ, หมวดหมู่ และจำนวนเงิน

โจทย์ที่ 4:สรุปรายงานการเงิน\
คำนวณและแสดง: ยอดรายรับรวม, ยอดรายจ่ายรวม และยอดเงินคงเหลือสุทธิ (รายรับรวม - รายจ่ายรวม)

โจทย์ที่5: เพิ่มปุ่มล้างประวัติทั้งหมด\
 เพิ่มปุ่ม "ล้างข้อมูลทั้งหมด" ที่ด้านล่างของรายการธุรกรรม เมื่อกดแล้วให้แสดงกล่องยืนยัน (confirm()) หากผู้ใช้กดยืนยัน ให้ล้างข้อมูลทั้งหมดในตารางและอัปเดตยอดเงินให้เป็น ฿0.0
