โจทย์ที่ 1: แปลงค่าแบบสองทิศทาง
พัฒนาระบบให้สามารถกรอกจำนวนเงินที่ช่องปลายทาง (amount-two) แล้วคำนวณย้อนกลับมายังช่องต้นทาง (amount-one) ได้

โจทย์ที่ 2: สร้างประวัติการแปลงเงิน
สร้างส่วนแสดงผล "ประวัติการแปลงเงินย้อนหลัง 10 รายการล่าสุด" เก็บรายการแปลงเงินล่าสุดอย่างน้อย 10 รายการ แล้วแสดงใต้เครื่องมือ เช่น 1,000 THB → 28.17 USD พร้อมปุ่มล้างประวัติ

โจทย์ที่ 3:เพิ่มปุ่มล้างข้อมูล
สร้างปุ่ม “ล้างข้อมูล” เพื่อคืนค่า Input ทั้งสองช่องเป็นค่าว่างหรือค่าเริ่มต้น และเปลี่ยนข้อความอัตราแลกเปลี่ยนกลับเป็นสถานะเริ่มต้น

โจทย์ที่ 4: แสดงเวลาที่อัปเดตล่าสุด
เพิ่มข้อความบอกเวลาปัจจุบัน เพื่อให้ผู้ใช้ทราบว่าข้อมูลอัตราแลกเปลี่ยน ถูกดึงมา เวลาใด
